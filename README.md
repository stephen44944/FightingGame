# 🎮 双人横版对战拳皇游戏

![Python](https://img.shields.io/badge/Python-3.8+-blue?logo=python)
![Pygame](https://img.shields.io/badge/Pygame-2.0+-green?logo=pygame)
![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20macOS%20%7C%20Linux-lightgrey)
![License](https://img.shields.io/badge/License-MIT-yellow)

基于 **Pygame** 开发的本地双人横版对战格斗游戏。两名玩家同台竞技，选择各自角色在垂直滚动的地图上展开实时对决！

---

## 🎯 游戏特色

- **8 名可选角色** — 关羽、K、Poena、弓箭手、Darling、蜘蛛王子、Iccy、Ghost，各有独特属性与技能
- **近战 & 远程** — 战士用剑，射手用子弹，攻击风格截然不同
- **被动技能系统** — 每名角色拥有专属被动（狂暴之心、武圣、闪避大师、鹰眼、蛛网、暗影、灵体、冰霜）
- **可破坏地形** — 草地、木板、石砖、冰块、玻璃、铁块、火焰、水面等 8 种材质
- **特殊地图元素** — 传送门、弹跳板、治疗区、加速带、冰面、陷阱、移动平台
- **掉落道具** — HP 药水、MP 药水、加速鞋、护甲等增益
- **图片缓存优化** — 启动时预加载所有资源，运行流畅不掉帧
- **鼠标 & 键盘双支持** — 主菜单、选角、结算均可鼠标操作

## 🚀 快速开始

```bash
python gayforce.py
```

游戏以 800×600 窗口启动，锁 60 FPS。首次运行图片缓存预加载可能稍慢 2-5 秒。

## 🎮 操作说明

### 主菜单 & 选角

| 功能 | 玩家1 | 玩家2 |
|------|-------|-------|
| 移动光标 | W/A/S/D | ↑/←/↓/→ |
| 确认选择 | Enter | 小键盘 Enter |

> 也支持鼠标悬停和点击！

### 对战操作

| 动作 | 玩家1 | 玩家2 |
|------|-------|-------|
| 跳跃 | **W** | **↑** |
| 左/右移动 | **A/D** | **←/→** |
| 向下穿平台 | **S** | **↓** |
| 普通攻击 | **J** | **小键盘 1** |
| 技能攻击 (MP) | **L** | **小键盘 3** |

│   │   ├── special_bricks.py   # 特殊地图元素
│   │   ├── image_cache.py      # 图片缓存系统

│       ├── main_menu.py     # 主菜单

## 📝 改进亮点

1. **图片缓存系统** — `ImageCache` 全局缓存，帧率提升 30-50%
2. **被动技能系统** — `PassiveSkill` 基类 + 8 子类，策略深度大幅提升
3. **特殊地图元素** — 7 种交互砖块（传送门、弹跳板、治疗区等）
4. **鼠标全流程支持** — 菜单、选角、结算均可鼠标操作
5. **平衡性优化** — 伤害调整、1 条命制、复活冷却优化
